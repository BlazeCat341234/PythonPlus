# Python+

# How to use:

## For MacOS / Linux
- Make sure you have Python>3.10 installed
- Clone or download Python+
- Navigate to directory
- Execute `python3 -m pyplus examples/hello.pyplus` to run the file `examples/hello.pyplus`

## Syntax for v0.5

To declare variables:
```
[varname] := [value]
```

To print a value:
```
print [variable, string, or maths]
```

To use an if statement:
```
if [condition]
    [code to run]
end
```

Available maths operators:
`+, -, /, *, (, )`

Other syntax:
- Commas
- Booleans
